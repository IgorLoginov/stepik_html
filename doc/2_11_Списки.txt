
Списки

Списки в HTML помогают организовать информацию и сделать контент более 
структурированным и удобным для чтения.

Существует три основных тега для списков:

Ненумерованные списки <ul> (от английского "unordered list" — ненумерованный список) 
Нумерованные списки <ol> (от английского "ordered list" — нумерованный список) 
Списки определений <dl> (от английского "description list" — список определений )

Каждый элемент списка обозначается тегом <li> 
(от английского "list item" — элемент списка) 

Тег <ul> используется когда нам нужно создать список без нумерации 
(без определенного порядка)
По умолчанию каждый элемент списка будет маркироваться кружком.

<h2>Любимые фильмы</h2>
<ul>
  <li>Интерстеллар</li>
  <li>Начало</li>
  <li>Темный рыцарь</li>
  <li>Побег из Шоушенка</li>
</ul>

📌 Кроме стандартного кружка, существует множество других маркеров для списков. 
Вы также можете задать свой собственный стиль маркера, используя CSS-стили.

Тег <ol> используется когда нам нужен пронумерованный список

Порядковые номера браузер выставляет автоматически, используйте этот 
тег для пошаговых инструкций или в любых других ситуациях, когда важен порядок.

<h2>Как приготовить омлет</h2>
<ol>
  <li>Взбейте яйца в миске.</li>
  <li>Добавьте соль и перец по вкусу.</li>
  <li>Разогрейте сковороду с маслом.</li>
  <li>Вылейте яичную смесь на сковороду.</li>
  <li>Готовьте до золотистой корочки.</li>
</ol>


Тег <dl> используется когда нам нужен список терминов и их описаний
<dl> — Это список для терминов и определений
<dt> — Это сам термин (от английского "definition term" — определение термина).
<dd> — Это описание термина (от английского "definition description" — 
       определение описания).

* В реальной практике использование тега <dl> встречается сильно реже, 
в отличии от других двух.

<dl>
    <dt>HTML</dt>
    <dd>Язык разметки, используемый для создания веб-страниц.</dd>

    <dt>CSS</dt>
    <dd>Язык стилей, используемый для описания внешнего вида веб-страниц.</dd>

    <dt>JavaScript</dt>
    <dd>Язык программирования, который позволяет создавать интерактивные элементы на веб-страницах.</dd>
</dl>

Вложенные списки
Вы можете создавать иерархию, где один список включает в себя другой. 
Это помогает удобнее организовать сложную и объемную информацию.

Теги
HTML Теги — это специальные команды, заключенные в угловые 
скобки < >, которые используются для разметки текста и других
 элементов на веб-странице. 

Каждый тег обычно состоит из пары открывающего и закрывающего тегов.

У каждого тега есть своя роль, с их помощью мы описываем содержимое
 веб-страницы: параграфы, заголовки, изображения, ссылки и так далее.

Пример парных тегов

<p>Это параграф текста.</p>

Одиночные теги (самозакрывающиеся)

Некоторые теги не требуют закрывающего тега, они используются для 
обозначения элементов которые не содержат вложенного контента.

Вот несколько примеров таких тегов:

<br> — перенос строки на новую строку
<img> — добавление изображения
<hr> — горизонтальная линия
<input> — элемент формы для ввода данных

Список всех доступных тегов https://doka.guide/html/. 

(Все их знать не обязательно, но ознакомиться полезно)

==========
Атрибуты
==========

Это дополнительные сведения об элементах. Какие-то из них являются 
обязательными, а какие-то просто добавляют дополнительную информацию.

Они указываются рядом с тегом и выглядят так:
<тег_элемента имя_атрибута="значение_атрибута">

Пример
Посмотрим на тег <a> , который добавляет ссылку на страницу.

<a href="https://stepik.org">Перейти на Stepik</a>

Здесь атрибут href указывает URL-адрес ссылки. При нажатии на ссылку 
пользователь переходит на указанный сайт.

=======================
Универсальные атрибуты
=======================
Некоторые атрибуты, например, id, class и style, можно использовать с 
любыми HTML-элементами.

=====
- id — задает уникальный идентификатор для элемента, чтобы применить 
к нему CSS-стили или управлять им с помощью Javascript.

Важно: На одной странице не должно быть двух элементов с одинаковым 
значением атрибута id.

<div id="about">Блок о компании</div>

========
= class — задает класс элемента для стилизации с помощью CSS

<p class="big-text">Это большой текст.</p>


========
- style — указывает встроенные CSS-стили для элемента

<h1 style="color: red;">Красный заголовок</h1>


=====================
Уникальные атрибуты
=====================

Некоторые атрибуты, например href, применяются только к определённым 
тегам, в нашем случае к тегу <a>.

<a href="https://stepik.org">Перейти на Stepik</a>


Вот несколько других примеров:

======
src — применяется к элементу <img>, он указывает на источник изображения 
      или файла (ссылка или путь до файла на компьютере)
alt - добавляет текстовое описание изображения

<img src="images/поездки/Москва.jpg" alt="Москва">

<img src="https://images.unsplash.com/photo-1465146344425-f00d5f5c8f07" alt="Природа">

=========
type - используется в полях ввода  <input> для указания типа поля ввода 
       (например, text, password, checkbox и т.д.).

<input type="password" name="password">

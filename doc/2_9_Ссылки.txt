Ссылки
Тег <a> (от английского "anchor" — якорь)  используется для создания 
ссылок на другие страницы вашего сайта или на любые другие сайты в интернете. 
Тег один из самых важных, ведь он позволяет нам перемещаться по интернету.

Простой пример
<a href="https://stepik.org/">Перейти на Stepik</a>

В атрибуте href указывается необходимая ссылка, а внутри тега <a> 
размещается текст, который будет виден пользователю и на который он 
сможет кликнуть.

Ссылки бывают разных типов:

Простая ссылка на другую страницу
<a href="https://stepik.org/catalog/">Перейти в каталог Stepik</a>

Ссылка на электронную почту, укажите mailto: перед электронным адресом
<a href="mailto:harry.potter@hogwarts.com">Написать Гарри Поттеру</a>

Ссылка на телефонный номер, укажите tel: перед номером телефона
<a href="tel:+1234567890">Позвонить</a>

Ссылка на файл для скачивания, укажите атрибут download
<a href="files/passport.pdf" download>Скачать документ</a>


Как открыть ссылку в новой вкладке или окне браузера
К тегу <a> добавьте атрибут target, который определяет где будет 
открыта ссылка, а в качестве значения укажите _blank, тогда ссылка 
откроется в новом окне или вкладке в зависимости от настроек браузера.

<a href="https://yandex.ru/" target="_blank">Открыть Яндекс в новой вкладке</a>

Как добавить всплывающую подсказку на ссылку
Иногда полезно добавить дополнительную информацию на ссылку, наведя 
на нее, пользователь сможет ее прочитать.

Используйте атрибут title для этого.

Ссылки
Тег <a> (от английского "anchor" — якорь)  используется для создания 
ссылок на другие страницы вашего сайта или на любые другие сайты в интернете. 
Тег один из самых важных, ведь он позволяет нам перемещаться по интернету.

Простой пример
<a href="https://stepik.org/">Перейти на Stepik</a>

В атрибуте href указывается необходимая ссылка, а внутри тега <a> 
размещается текст, который будет виден пользователю и на который он 
сможет кликнуть.

Ссылки бывают разных типов:

Простая ссылка на другую страницу
<a href="https://stepik.org/catalog/">Перейти в каталог Stepik</a>

Ссылка на электронную почту, укажите mailto: перед электронным адресом
<a href="mailto:harry.potter@hogwarts.com">Написать Гарри Поттеру</a>

Ссылка на телефонный номер, укажите tel: перед номером телефона
<a href="tel:+1234567890">Позвонить</a>

Ссылка на файл для скачивания, укажите атрибут download
<a href="files/passport.pdf" download>Скачать документ</a>


Как открыть ссылку в новой вкладке или окне браузера
К тегу <a> добавьте атрибут target, который определяет где будет 
открыта ссылка, а в качестве значения укажите _blank, тогда ссылка 
откроется в новом окне или вкладке в зависимости от настроек браузера.

<a href="https://yandex.ru/" target="_blank">Открыть Яндекс в новой вкладке</a>

Как добавить всплывающую подсказку на ссылку
Иногда полезно добавить дополнительную информацию на ссылку, наведя 
на нее, пользователь сможет ее прочитать.

Используйте атрибут title для этого.

<a href="https://www.example.com/download" title="Скачать последнюю версию программы">Скачать</a>


================================
Подробнее об атрибутах ссылки
===============================

href — Указывает URL, на который ведет ссылка. Это обязательный атрибут.

Если указать #, то ссылка переместит пользователя вверх по текущей странице:

Пример использования:
<a href="#">Наверх</a>

Кроме того, значение # часто используется в качестве заглушки — временного 
значения для ссылки, когда ее адрес еще нам неизвестен, например, на 
начальном этапе разработки сайта.

target — Определяет, как открывать ссылку. Используйте этот атрибут 
только вместе с href.

_self — Открывает ссылку в том же окне/вкладке (значение по умолчанию)
_blank — Открывает ссылку в новом окне/вкладке
_parent — Открывает ссылку в родительском фрейме
_top — Открывает ссылку на всей странице

Пример использования:

<a href="https://yandex.ru" target="_blank">Открыть Яндекс в новом окне</a>

                  
На практике наиболее часто используется значение _blank.

download — Указывает, что ссылка предназначена для загрузки файла. Значение может быть указано для задания имени файла.

Пример использования:

<a href="file.zip" download="myfile.zip">Скачать файл</a>

====================================
Относительные и абсолютные ссылки
====================================

Адрес ссылки можно написать по разному, давайте разберем какие бывают виды.

==============
Абсолютные
Такая ссылка содержит полный адрес, включая протокол 
(например, http:// или https://), доменное имя и путь к определенной 
странице или файлу.

Пример абсолютной ссылки:
<a href="https://vk.com/about/">О нас</a>

                  
Такие ссылки всегда работают, независимо от того, где находится текущая страница
Полный адрес ссылки дает больше информации, что дает лучшее понимание 
куда она ведет

Когда использовать?
Тогда когда нужно указать ссылку на какой-то внешний сайт из интернета.

=============
Относительные
Такая ссылка указывает неполный путь относительно текущей страницы. 
Она не включает доменное имя и протокол.

Символ / в начале такой ссылки указывает, что она ведет от корня текущего сайта.

Например, в этой ссылке https://stepik.org/catalog/ корнем является 
https://stepik.org.

Пример относительной ссылки:

<a href="/catalog/">Перейти на каталог Stepik</a>

Эта ссылка перенаправит вас в каталог сайта Stepik. 
Поскольку вы уже находитесь на этом сайте, относительная ссылка 
/catalog/ будет воспринята браузером как полный 
адрес: https://stepik.org/catalog/.

Такие ссылки полезны в случае когда сайт был перенесен на другой 
домен или сервер и корневой адрес изменился
Для некоторых пользователей может быть неочевидным куда будет вести 
ссылка если она указана не полностью

Когда использовать?
Предпочтительнее для внутренних страниц вашего сайта, так как они 
упрощают навигацию внутри одного проекта, не нужно будет каждый раз 
указывать основной домен сайта.

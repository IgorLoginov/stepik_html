
Формы

Тег <form> используется для добавления форм на страницу, в них пользователи 
вводят данные, которые потом отправляются на сервер для обработки. 
Например, форма для регистрации пользователя на сайте или форма "Оставить заявку".

Пример №1 Форма для входа в личный кабинет на сайте СДЭК

см. рис. Формы_1

Форма содержит в себе другие HTML-элементы:

Поля для ввода <input />
Кнопки <button>
Различные переключатели, например <input type="checkbox" />

=================
Структура формы
=================

Тег <form> имеет несколько атрибутов, которые помогают определить, 
как и куда данные будут отправляться.


Основные атрибуты:

- action — указывает URL-адрес, на который будут отправлены данные формы. 
           Например, это может быть адрес скрипта на сервере, который будет 
           обрабатывать полученные данные.

- method — определяет метод HTTP,  который используется для отправки данных. 
           Например, метод GET подходит для получения данных, 
           а метод POST — для их отправки

Пример простой формы:
<form action="/send.php" method="POST">
    <!-- Поля ввода будут здесь -->
</form>

Форма сама по себе не имеет визуального представления, она состоит из 
различных элементов, таких как поля ввода, кнопки и другие компоненты. 
Она служит "контейнером" для элементов с которыми будет 
взаимодействовать пользователь.

==============
Поля ввода
Внутри тега <form> мы можем добавлять различные поля, например, чтобы ввести 
текст, пароль или поставить галочку (флажок).

Давайте рассмотрим несколько типов полей ввода:

===============
Текстовое поле

Для ввода текстовой информации используется элемент <input> с типом text.

<label for="username">Имя пользователя:</label>
<input type="text" id="username"  name="username" placeholder="Введите имя" required>

Тег <label> отвечает за текстовую подпись поля. Он связывает текст с полем ввода.

!!!!!!
Атрибут for должен совпадать с id поля.

Атрибут  required делает поле обязательным для заполнения.

Атрибут placeholder добавляет подсказку "Введите имя", она исчезает 
если начать вводить текст.


================
Поле для пароля
================
Для ввода паролей используется элемент <input> с типом password.

<label for="password">Пароль:</label>
<input type="password" id="password"  name="password">

===================
Электронная почта
Для ввода адреса электронной почты используется тип email.

<label for="email">Электронная почта:</label>
<input type="email" id="email" name="email" required>

=================
Чекбокс (флажок)
Для добавления флажка в форму используется типом checkbox 
(от английского "check box" — "галочка", "флажок").

<label for="newsletter">Подписаться на новости</label>
<input type="checkbox" id="newsletter" name="newsletter">

==================
Кнопка отправки
Чтобы отправить форму, необходимо добавить кнопку типа submit.

В качестве кнопки можно использовать тег <input> или тег <button>.

<input type="submit" value="Отправить">

<button type="submit">Отправить</button>

📌 Рекомендуется использовать тег <button>, в отличие от <input> 
у него нет ограничений по стилизации и добавлении внутреннего содержимого. 

Пример
Форма отправляет имя пользователя, адрес электронной почты и пароль на сервер. 
В атрибуте action указано, что данные будут обработаны скриптом, 
расположенным в корневой папке сайта по адресу /send.php.

Добавим CSS-стили, чтобы расположить элементы формы друг под другом с отступами.

form input,
label,
button {
  display: block;
  margin-bottom: 8px;
}
input[type="checkbox"],
label[for="newsletter"] {
  display: inline;
}

Добавим HTML-разметку для полей формы и кнопки отправки.

<form action="/send.php" method="POST">
  <label for="username">Имя пользователя:</label>
  <input type="text" id="username" name="username" required />

  <label for="email">Электронная почта:</label>
  <input type="email" id="email" name="email" required />

  <label for="password">Пароль:</label>
  <input type="password" id="password" name="password" required />

  <input type="checkbox" id="newsletter" name="newsletter" />
  <label for="newsletter">Подписаться на новости</label>

  <button type="submit">Зарегистрироваться</button>
</form>

📌 Сейчас большинство современных сайтов и веб-приложений используют 
Javascript для отправки данных без перезагрузки страницы, в этом помогает 
технология AJAX (Asynchronous JavaScript and XML — Асинхронный Javascript и XML).

===============================
Подробнее о типах полей ввода
===============================
Помимо привычных полей для ввода текста, пароля или электронной почты, 
в HTML существует множество других, которые расширяют возможности взаимодействия 
с пользователем.

Давайте рассмотрим некоторые из них:

======
1. tel — Поле для ввода телефона, помогает выводить цифровую клавиатуру, 
         чтобы удобнее вводить номер телефона на мобильном устройстве.

<label for="phone">Номер телефона:</label>
<input type="tel" id="phone" name="phone">

Источник: https://developer.mozilla.org/ru/docs/Web/HTML/Element/input/tel


============
2. checkbox — Чекбоксы (флажки), позволяют выбрать несколько вариантов из списка.

<label>Выберите ваши интересы:</label>

<input type="checkbox" id="music" name="interests" value="music">
<label for="music">Музыка</label>

<input type="checkbox" id="sports" name="interests" value="sports">
<label for="sports">Спорт</label>

<input type="checkbox" id="travel" name="interests" value="travel">
<label for="travel">Путешествия</label>

=============
3. radio — Переключатели (радио-кнопки), позволяют выбрать один из 
           нескольких вариантов в списке.

<label>Выберите ваш пол:</label>

<input type="radio" id="male" name="gender" value="male">
<label for="male">Мужчина</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">Женщина</label>

==========
4. date — Поле для ввода даты, открывает календарь при нажатии на дату.
<label for="birthday">Дата рождения:</label>
<input type="date" id="birthday" name="birthday"> 

==========
5. time — Позволяет выбрать время.

<label for="appointment">Время встречи:</label>
<input type="time" id="appointment" name="appointment">

===========
6. color — Позволяет выбрать цвет из палитры.

<label for="favcolor">Любимый цвет:</label>
<input type="color" id="favcolor" name="favcolor">

7. file — Поле для загрузки файла, позволяет выбрать файл с 
   устройства пользователя, например, чтобы прикрепить фото к электронному письму.

<label for="file-upload">Загрузите файл:</label>
<input type="file" id="file-upload" name="file-upload">


Семантика

Существует множество тегов HTML, которые по своему названию передают смысл и 
содержание элементов. Эти теги называются семантическими.

Семантические теги необходимы для точного описания содержимого 
страницы и ее структуры.

Каждый семантический элемент выполняет уникальную роль и должен использоваться 
в соответствии с его назначением.

Например, тег <p> предназначен для обозначения параграфа, 
а <ul> — для создания неупорядоченного списка.

Некоторые теги можно использовать для разметки всей структуры страницы.

см. рис. Семантика

Название этих тегов передает их смысл:

-  <header> — подходит для разметки шапки сайта, например, где будет логотип, 
              навигация и кнопка "Оставить заявку"

- <nav> — предназначен для навигационных ссылок, группирует их в один общий блок

- <main> — определяет основное содержимое страницы, каждая страница может 
           иметь только один тег <main>, по аналогии с тегом <h1>

- <section> — разделяет контент сайта на отдельные логические секции, 
              рекомендуется у каждой секции добавлять заголовок

- <article> — используется для самостоятельного содержимого, которое можно 
              опубликовать отдельно, например, статья, карточка 
              пользователя или товара

- <aside> — блок для дополнительного содержимого, которое не связано с основным, 
            например, для боковой панели сайта или блока с заметками

- <footer> — подходит для самой нижней части сайта, где указывается 
             информация об авторских правах, ссылки, политика конфиденциальности 
             или повторяется навигации сайта в более расширенном формате
 
 - <figure> — используется для иллюстраций, диаграмм или изображений, 
              а <figcaption> — для добавления подписи к ним.

Почему нужно обращать внимание на семантику

Правильное использование семантических тегов улучшает доступность сайта, 
делает код более понятным как для разработчиков, так и для машин.

- Улучшение доступности для людей с ограничениями по зрению
  Экранные читалки лучше распознают и диктуют содержимое страницы в слух.

- SEO-оптимизация
      Поисковые системы лучше понимают структуру и содержание страниц. 
      Это улучшает позицию сайта в Яндексе, Google и так далее.

- Читаемость кода
     Код легче читать и поддерживать (ваши коллеги скажут спасибо).

Посмотрите на разницу
❌ Неправильно

Мало семантических тегов и слишком много <div>.

<div>
  <div>
    <h1>Интернет-магазин</h1>
  </div>
  <div>
    <div>
      <div><a href="#">Главная</a></div>
      <div><a href="#">Товары</a></div>
      <div><a href="#">О компании</a></div>
      <div><a href="#">Контакты</a></div>
    </div>
  </div>
</div>

<div>
  <div>
    <h1>Техника</h1>
  </div>
  <div>
    <div>
      <h2>Стиральные машины</h2>
    </div>
    <div>
      <p>Найдено 509 товаров</p>
      <p>Различные виды: узкие, с сушкой и тд</p>
    </div>
  </div>
  <div>
    <div>
      <h2>Кофеварки</h2>
    </div>
    <div>
      <p>Найдено 230 товаров</p>
      <p>Различные виды: рожковые, капельные и тд</p>
    </div>
  </div>
</div>

<div>
  <p>2025 Интернет-магазин. Все права защищены.</p>
</div>

Из-за избыточного использования <div>, стало сложнее читать разметку страницы.

✅ Правильно

А теперь перепишем этот код с использованием семантических тегов.

<header>
  <h1>Интернет-магазин</h1>
  <nav>
    <ul>
      <li><a href="#">Главная</a></li>
      <li><a href="#">Товары</a></li>
      <li><a href="#">О компании</a></li>
      <li><a href="#">Контакты</a></li>
    </ul>
  </nav>
</header>

<main>
  <h1>Техника</h1>
  <section>
    <h2>Стиральные машины</h2>
    <p>Найдено 509 товаров</p>
    <p>Различные виды: узкие, с сушкой и тд</p>
  </section>
  <section>
    <h2>Кофеварки</h2>
    <p>Найдено 230 товаров</p>
    <p>Различные виды: рожковые, капельные и тд</p>
  </section>
</main>

<footer>
  <p>2025 Интернет-магазин. Все права защищены.</p>
</footer>

❗️ Избегайте избыточного использования
Применяйте семантические теги там, где это логично и способствует улучшению 
структуры страницы. 

В остальных ситуациях смело используйте универсальный тег <div> или другие теги.

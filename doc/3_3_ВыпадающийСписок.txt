
Выпадающий список

Тег <select> (от английского "select" — выбирать) создает выпадающий 
    список, который позволяет пользователям выбрать одно или несколько 
    из предложенных вариантов.

Для добавления вариантов используется тег <option> 
(от английского "option" — вариант). 

У этого тега есть обязательный 
атрибут value, который содержит значение, отправляемое на сервер 
при отправке формы.

Например, вам предлагается выбрать город проживания в своем профиле 
на сайте

<select name="city">
    <option value="Москва">Москва</option>
    <option value="Санкт-Петербург">Санкт-Петербург</option>
    <option value="Нижний Новгород">Нижний Новгород</option>
</select>

Чтобы выбирать несколько вариантов из списка, используйте атрибут 
multiple

<h2>Выберите ваши любимые фрукты:</h2>
<select name="fruits" multiple>
  <option value="apple">Яблоко</option>
  <option value="banana">Банан</option>
  <option value="orange">Апельсин</option>
  <option value="grape">Виноград</option>
  <option value="kiwi">Киви</option>
</select>

Можно выбирать варианты используя клавиатуру
Список <select> автоматически поддерживает управление с клавиатуры. 
Вы можете легко перемещаться по списку вариантов с помощью клавиш 
стрелок и выбирать их с помощью клавиши Enter или Space.

📌 Ограничение в стилизации

Есть ряд ограничений в браузерах которые не позволяют нам сильно 
изменить внешний вид выпадающего списка, стандартные свойства CSS не 
всегда применимы к элементам <select>.

Помимо этого, большинство браузеров по разному отображают выпадающие 
списки, они могут значительно различаться друг от друга. 
Это создает сложности при создании единообразного вида списка.

Поэтому, чтобы создать свой уникальный внешний вид выпадающего списка, 
разработчики создают его с нуля используя комбинацию 
HTML, CSS и Javascript. 

Это позволяет сделать любой внешний вид и поведение, но лишает 
встроенных возможностей <select>, например выбора вариантов с клавиатуры.

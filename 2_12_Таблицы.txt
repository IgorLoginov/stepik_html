
Таблицы

Тег <table> используется для создания таблиц, они позволяют организовать 
данные в виде строк и столбцов, что делает информацию более понятной и 
структурированной.

Например, вы можете использовать таблицы для расписаний, результатов, 
статистики и многого другого.

Чтобы создать таблицу, вам понадобятся несколько тегов:

<table> — основной тег, который определяет таблицу, ее начало и конец.

<tr> (от английского "table row" — строка таблицы) — тег для строки таблицы

<td> (от английского "table data" — данные таблицы) — тег для ячейки с данными в строке

<th> (от английского "table header" — заголовок таблицы) — это тег заголовка ячейки. 
     Он выделяет текст, делая его жирным и по центру.
Пример простой таблицы

В этом примере создается таблица с заголовками "Имя", "Возраст" и "Город". 
Каждая строка содержит информацию о человеке.


<table>
    <tr>
        <th>Имя</th>
        <th>Возраст</th>
        <th>Город</th>
    </tr>
    <tr>
        <td>Иван</td>
        <td>25</td>
        <td>Москва</td>
    </tr>
    <tr>
        <td>Мария</td>
        <td>30</td>
        <td>Санкт-Петербург</td>
    </tr>
    <tr>
        <td>Алексей</td>
        <td>22</td>
        <td>Екатеринбург</td>
    </tr>
</table>


Как улучшить внешний вид таблицы

По умолчанию таблица выглядит некрасиво, у ячеек нет границ и поэтому 
столбцы и строки сливаются между собой. Настроить вид таблицы можно через CSS-стили.

Существует еще один способ, но использовать его не рекомендуется, 
для ознакомления кратко рассмотрим его.

❗️Устаревшие атрибуты таблицы

Ранее у тега <table> существовало несколько атрибутов, которые позволяли без CSS менять внешний вид таблицы, например:

Добавлять границы вокруг таблицы — border
Увеличивать расстояния между ячейками — cellspacing
Увеличивать внутренний отступ у ячеек — cellpadding
Менять размеры самой таблицы — width и height
Сегодня, в современной веб-разработке эти атрибуты считаются устаревшими. 
Вместо этого используйте CSS-стили, это позволяет управлять внешним видом 
таблиц более гибко и эффективно.

Используем CSS
Давайте добавим небольшой CSS код, чтобы улучшить вид таблицы.

<style>
table {
  border-collapse: collapse; <!-- Делает разделительные линии таблицы едиными между собой -->
}
th,
td {
  border: 1px solid black; <!-- Добавляет черные разделительные линии для ячеек -->
  padding: 8px; <!-- Добавляет внутренние отступы в ячейках, добавляя им побольше пространства -->
}
th {
  background-color: #d3d3d3; <!-- Задает фоновый серый цвет для ячеек заголовков -->
}
</style>

Теперь, добавим этот код выше нашей разметки таблицы.

​<style>
table {
  border-collapse: collapse;
}
th,
td {
  border: 1px solid black;
  padding: 8px;
}
th {
  background-color: #d3d3d3;
}
</style>

Дополнительные элементы для таблицы:
<thead> группирует заголовки таблицы
<tbody> группирует тело таблицы
<tfoot> группирует итоги или заключительные строки таблицы

<table>
  <thead>
    <tr>
      <th>Продукт</th>
      <th>Количество</th>
      <th>Цена</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Яблоки</td>
      <td>5 кг</td>
      <td>100 руб.</td>
    </tr>
    <tr>
      <td>Бананы</td>
      <td>3 кг</td>
      <td>150 руб.</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2">Итого:</td>
      <td>250 руб.</td>
    </tr>
  </tfoot>
</table>

Атрибут colspan  объединяет нужное количество ячеек в одну. Мы указали количество 2, 
поэтому ячейка Итого объединила Продукт и Количество в одну.

📌 Используйте по назначению
Когда вам нужно показать табличные данные используйте тег <table>, 
это улучшит качество и понимание вашего кода как для других 
разработчиков (коллег) так и для поисковых роботов.

Избегайте использования таблиц в декоративных целях или для разметки структуры 
страницы, такой подход считается устаревшим.
